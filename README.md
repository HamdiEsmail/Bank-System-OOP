# Bank System OOP 🏦

A console-based banking system built with C++ using Object-Oriented Programming concepts.

This project simulates a banking system with client management, user management,
authentication, permissions, transactions, and file-based data storage.

## 🚀 Features

### 👤 Client Management
- Add new clients
- Delete clients
- Update client information
- Find clients
- List all clients
- Manage client accounts

### 💰 Banking Operations
- Deposit money
- Withdraw money
- Transfer money between clients
- View transfer history
- Record transaction logs

### 🔐 User Management & Authentication
- User login system
- Username and password validation
- Password encryption
- Logout functionality
- Return to the login screen
- Lockout after 3 failed login attempts
- User permissions
- Logged-in user information
- Login logging
- View login logs based on permissions

### 🛠️ System Features
- Menu-based navigation
- Input validation
- File-based data storage
- Read and save data from files
- Search and update records
- Permission-based access
- Separate screens for different operations
